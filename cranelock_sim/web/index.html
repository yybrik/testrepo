What do the results mean?

What is a run? One system tested in one situation with one request sequence. A sequence number (also called a seed) lets us repeat the same requests. It is not a crane number.
Crane names: A = Crane 1, B = Crane 2, C = Crane 3. They share one lane; only one may occupy it at a time.

How are the three systems different?

Central lock · referenceOne coordinator chooses the next crane. It can still assign another crane if a crane fails, provided the coordinator stays available.

Basic tokenCranes pass one token. Only its holder may request lane entry. This version cannot replace the token if its holder stops.

CraneLockAdds majority-approved recovery and checks against old permissions. Recovery changes digital authority; it never proves the lane is empty.
